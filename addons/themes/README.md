# themes

[api] = 2
[version] = 1.2.0
[authors] = {"Aarav Maloo"}
[description] = <Pick one of blob's 21 built-in themes with a live preview>
[keybind] = c
[mode] = workspace
[permissions] = {"write-notes"}

A built-in theme switcher that lists available color presets with a live preview of blob in the highlighted theme. Move with the arrow keys or `k`/`j` and the preview recolours as you go; `Enter` applies the theme to blob's config file and blob picks it up as soon as the selector closes, `Esc` keeps your current theme.
